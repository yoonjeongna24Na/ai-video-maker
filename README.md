# AI 영상 메이커 (초기 실행 버전)

휴대폰과 PC 브라우저에서 같은 주소로 접속해 사용하는 단계별 AI 영상 제작 웹앱입니다.

## 포함 기능
- 프로젝트 이름, 영상 비율 설정 (유튜브 가로 16:9 / 쇼츠 9:16 / 정사각형)
- 대본을 문장 단위 장면 초안으로 분할
- 장면 설명 및 움직임 프롬프트 수정
- OpenAI 이미지 API로 장면 이미지 생성
- 이미지 업로드 및 승인 단계
- Kling 3.0 Image-to-Video 요청
- Kling 작업 상태 확인 및 장면별 영상 다운로드

## 필요한 것
- Node.js 20 이상
- OpenAI API 키 (이미지 생성 비용 발생 가능)
- Kling API 키 및 영상 생성 리소스 (영상 생성 비용 발생 가능)

일반 Kling 웹사이트 로그인과 API 사용 권한은 별개입니다. Kling 개발자 콘솔에서 API 키와 리소스 패키지를 준비해야 합니다.

## 실행 방법
1. 압축을 풀고 이 폴더에서 터미널을 엽니다.
2. `.env.example`을 `.env`로 복사합니다.
3. `.env` 파일에 본인의 `OPENAI_API_KEY`와 `KLING_API_KEY`를 입력합니다.
4. 실행:
   ```bash
   npm start
   ```
5. PC에서 `http://localhost:3000`을 엽니다.

## 휴대폰에서 접속
PC와 휴대폰을 같은 Wi-Fi에 연결하고, PC의 로컬 IP 주소를 확인한 뒤 휴대폰 브라우저에서 `http://PC의-IP:3000`으로 접속합니다. 외부 인터넷에서도 접속하려면 HTTPS가 적용된 서버에 배포해야 합니다.

## 중요한 보안 안내
- API 키를 웹페이지에 입력하거나 공유하지 마세요.
- `.env` 파일을 다른 사람에게 보내지 마세요.
- `.env`는 저장소에 올리지 마세요.
- API 사용량과 요금은 각 제공업체 콘솔에서 확인하세요.

## 현재 버전의 한계
- 대본 분할은 문장 기준의 간단한 초안이며, AI 시나리오 분석은 아직 연결하지 않았습니다.
- Kling 영상은 장면별로 생성하고 다운로드할 수 있습니다. 일반 유튜브 영상은 가로 16:9 구도를 목표로 하며, 쇼츠는 세로 9:16 구도를 목표로 합니다. 실제 출력 비율은 Kling API 모델/요청 옵션의 지원 여부에 따라 확인이 필요합니다.
- 최종 MP4 자동 이어붙이기, 자막·음악 자동 편집, 프로젝트 클라우드 저장은 아직 포함되지 않았습니다.
- Kling API는 계정/지역/요금제/모델 지원에 따라 요청 제한이나 입력 형식이 달라질 수 있습니다.
